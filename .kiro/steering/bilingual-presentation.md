# Bilingual Presentation Standards

1. **English Primary**: Source code, identifiers, comments, error codes, CLI default output, and hackathon presentation collateral must be in standard professional English.
2. **Chinese (ZH) Localization Toggle**: Complete bilingual parity must be provided via `--lang=zh`, `AI_WORKFLOW_LANG=zh`, or the UI header toggle.
3. **Standard Terminology Mapping**:
   - Dynamic Workflow $\leftrightarrow$ 动态工作流
   - Code, Not Conversation $\leftrightarrow$ 代码优先，拒绝对话
   - Deterministic Probing $\leftrightarrow$ 确定性环境探测
   - Durable Replay $\leftrightarrow$ 持久化断点回放
   - Timeline DAG $\leftrightarrow$ 时序有向无环图
   - Live Kanban $\leftrightarrow$ 实时工件看板
   - Skeleton Crew $\leftrightarrow$ 骨架班底模板
